# Support

- **Documentation**: start with [docs/](docs/), especially
  [Troubleshooting](docs/troubleshooting.md).
- **Questions** ("how do I ...?"): open a discussion in
  [Q&A](https://github.com/pessom/wireguard-exporter/discussions/categories/q-a).
- **Bugs and feature requests**: open an
  [issue](https://github.com/pessom/wireguard-exporter/issues/new/choose) using
  one of the templates.

This is a community project maintained in spare time; there is no guaranteed
response time. Issues waiting for information from the author (label
`needs-info`) are closed automatically after 21 days without a reply and can
be reopened at any time.
